# خادم طلبات بقالة سواحل

هذا خادم أولي لاستقبال الطلبات من صفحة ويب عامة. يجب تشغيله على استضافة متاحة عبر الإنترنت حتى يستطيع العملاء فتح رابط الطلب من خارج شبكة المحل.

## التشغيل التجريبي

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/Termux: source .venv/bin/activate
pip install -r requirements.txt
# عيّن رمزاً سرياً قوياً قبل النشر
# Linux/Termux: export SAWAHIL_ADMIN_TOKEN='ضع-رمزاً-سرياً-طويلاً'
python app.py
```

افتح `/` لواجهة العميل. لإضافة صنف تجريبي:

```bash
curl -X POST http://127.0.0.1:8000/api/products \\
 -H 'Content-Type: application/json' -H 'X-Admin-Token: ضع-رمزاً-سرياً-طويلاً' \\
 -d '{"name":"ماء 1.5 لتر","price":200,"unit":"حبة"}'
```

قائمة الطلبات للإدارة: `GET /api/orders` مع ترويسة `X-Admin-Token`.

## مهم قبل الاستخدام الحقيقي
- لا تنشر الخادم على الإنترنت قبل تغيير `SAWAHIL_ADMIN_TOKEN` واستخدام HTTPS وحماية المعدل والنسخ الاحتياطي.
- هذه النسخة لا ترسل إشعار دفع (Push) إلى الهاتف ولا ترسل WhatsApp تلقائياً؛ واجهة الطلب تستقبل الطلب وتخزنه. يلزم ربط تطبيق Flutter بعنوان الخادم وإعداد خدمة إشعارات ومزود WhatsApp Business لإكمال الاستقبال الفوري والقناة الثانية.
- بيانات الأصناف في خادم الويب مستقلة مؤقتاً عن قاعدة تطبيق الهاتف؛ يلزم تفعيل مزامنة الأصناف قبل فتح المتجر للعملاء.
